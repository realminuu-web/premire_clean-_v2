# 📖 [프리미어 클린] 관리자 설명서

홈페이지의 글자·사진·후기·검색 설정은 이제 **관리자 페이지**에서 고칩니다. 코드를 몰라도 됩니다.

- 관리자 페이지 주소: **홈페이지 주소 뒤에 `/admin`** (예: `https://premierclean.co.kr/admin`)
- 홈페이지 맨 아래 오른쪽의 아주 작은 "관리자" 글자를 눌러도 들어갈 수 있어요.

## 1. 처음 설정 (한 번만)

관리자 페이지에서 고친 내용과 후기가 **모든 손님에게** 보이려면 온라인 저장소(Supabase)를 연결해야 합니다.
연결 전에는 "미리보기 모드"라서 지금 쓰는 컴퓨터에만 저장됩니다 (관리자 페이지 맨 위에 노란 안내가 보여요).

1. https://supabase.com 에서 무료 프로젝트를 하나 만듭니다.
2. Supabase 화면 왼쪽 **SQL Editor** 를 열고, 이 폴더의 `supabase/setup.sql` 내용을 통째로 붙여넣고 **Run** 을 누릅니다.
3. Supabase **Project Settings > API** 에서 두 값을 복사합니다.
   - `Project URL`
   - `service_role` 키 (⚠️ 비밀 키입니다. 절대 다른 사람에게 보여 주지 마세요)
4. 홈페이지를 올린 곳(예: Vercel)의 **환경 변수**에 아래를 넣습니다. 개발 컴퓨터에서는 `.env.local` 파일에 넣습니다.

```
SUPABASE_URL=복사한 Project URL
SUPABASE_SERVICE_ROLE_KEY=복사한 service_role 키
ADMIN_PASSWORD=관리자 비밀번호 (길고 어렵게)
ADMIN_SESSION_SECRET=아무 글자나 길게 (32자 이상, 로그인 유지용)
NEXT_PUBLIC_SITE_URL=https://실제도메인
```

> 🔒 관리자 비밀번호는 예전처럼 홈페이지 코드 안에 들어 있지 않습니다. 서버에만 있어서 손님이 볼 수 없어요.
> 개발 컴퓨터에서 `ADMIN_PASSWORD` 를 안 넣으면 임시 비밀번호 `0000` 이 쓰이지만, **실제 홈페이지에서는 꼭 넣어야** 로그인이 됩니다.

## 2. 시공 후기 올리기

관리자 페이지 왼쪽 **[시공 후기]** → **[+ 후기 올리기]**

| 칸 | 홈페이지 어디에 보이나요 |
|---|---|
| 청소 후 사진 | 후기 칸 오른쪽(컴퓨터) / 글 아래(휴대폰) 큰 사진 |
| 청소 전 사진 | 청소 후 사진이 없을 때 대신 보임 |
| 후기 내용 | 후기 칸 가운데 따옴표 글 |
| 고객 이름 | 동그라미 아이콘 옆 굵은 이름 (예: 김*현 고객님) |
| 지역 · 평수 | 이름 아래 작은 회색 글자 |
| 서비스 | 별점 옆, 사진 아래 |
| 보이기 / 숨겨 두기 | 끄면 홈페이지에서만 숨겨지고 목록에는 남아요 |

- 휴대폰 사진을 그대로 올려도 **자동으로 줄여서** 저장합니다.
- 올리면 홈페이지에 **바로** 나오고, 최신 후기가 맨 앞에 옵니다 (최대 10개가 돌아가며 보임).
- 후기를 하나도 안 올렸을 때는 예시 후기 4개가 보입니다. 첫 후기를 올리면 예시는 사라집니다.

## 3. 통계 보기

관리자 페이지 왼쪽 **[통계]** — 오늘 / 최근 7일 / 30일 / 90일

- **방문자**: 홈페이지에 들어온 사람 수 (같은 사람이 한 번 들어온 건 1명)
- **견적 신청**: 견적 칸에서 [신청하기]를 누른 수
- **전화·카톡·견적 버튼 누름**: 각 버튼을 누른 횟수
- **많이 본 섹션**: 손님이 어디까지, 어느 칸을 봤는지
- 이름·전화번호 같은 개인 정보는 통계에 기록하지 않습니다.

## 4. 문구 수정 (모든 글자)

관리자 페이지 왼쪽 **[문구 수정]**

- 홈페이지 위에서 아래 순서로 **12묶음**: 메뉴 줄 → 첫 화면 → 서비스 → 안심 보증 → 비포·애프터 → 시공 원칙 → 후기 글자 → 견적 칸 → 자주 묻는 질문 → 회사 정보 → 전화·카톡 → 인스타그램
- 칸마다 **📍 홈페이지 어디에 보이는 글자인지** 적혀 있습니다.
- 왼쪽 목록에서 지금 고치는 묶음이 **노랗게** 표시되고, **[홈페이지에서 이 위치 보기]** 를 누르면 그 자리가 새 창으로 열립니다.
- 맨 위 **검색 칸**에 "전화번호", "후불제"처럼 적으면 그 글자가 들어 있는 칸만 모아서 보여 줍니다.
- 다 고쳤으면 화면 맨 아래 **[저장하기]**. 저장하면 홈페이지에 바로 반영됩니다.
- 칸 오른쪽 **[기본값]** 을 누르면 그 칸만 처음 글자로 돌아갑니다. 맨 위 **[전체 기본값으로]** 는 모든 수정을 되돌립니다.
- "한 줄에 하나" 칸(케어 영역, 체크포인트, 평수 버튼)은 줄바꿈으로 항목을 나눕니다.
- 자주 묻는 질문은 **[질문 추가]**, ↑↓ 순서 바꾸기, 🗑 지우기가 됩니다.

> 💡 전화번호는 **[전화번호 · 카톡 · 아래 고정 버튼]** 묶음에서 한 번만 바꾸면 메뉴 줄·견적 칸·회사 정보·휴대폰 버튼까지 모두 바뀝니다.
> 전화 걸기 주소(`tel:1800-0000`)도 같이 바꿔 주세요.

## 5. 검색 노출 (네이버·구글·AI 검색)

관리자 페이지 왼쪽 **[검색 노출]**

- **검색 제목 / 검색 설명**: 네이버·구글 검색 결과에 보이는 파란 제목과 회색 설명. 화면 위 미리보기로 바로 확인할 수 있어요.
- **AI 검색용 회사 소개**: ChatGPT·Perplexity 같은 AI가 읽는 소개. 꾸밈말보다 "어디서, 무엇을, 어떻게"를 사실대로 쓰면 인용되기 좋습니다.
- **검색 태그 / 서비스 지역**: 지역과 서비스를 합친 태그("강남구 입주청소" 등)는 자동으로 만들어집니다.
- **네이버·구글 인증키**: 각 사이트에서 소유 확인용으로 받은 글자를 붙여넣습니다.

자동으로 해 두는 것 (손댈 필요 없음):
- 업체 정보(상호·전화·주소·영업시간·서비스 지역·서비스)를 검색엔진·AI가 읽는 형식으로 넣음
- 자주 묻는 질문을 검색 결과·AI 답변용 형식으로 넣음
- ChatGPT·Claude·Perplexity·구글·네이버·다음 로봇 허용 (`/robots.txt`), 관리자 페이지는 막음
- AI용 요약 파일 `/llms.txt`, 사이트 지도 `/sitemap.xml`

## 7. 네이버 플레이스·구글 비즈니스 등록 (사장님이 직접)

AI 검색과 지도 검색은 **홈페이지·네이버 플레이스·구글 비즈니스 프로필의 상호·전화·주소가 똑같을 때** 가장 잘 나옵니다.
사장님 계정이 필요해서 대신 등록해 드릴 수 없습니다.

1. **네이버 스마트플레이스** (https://smartplace.naver.com) — 업체 등록 → 업종 "청소업체" → 홈페이지 주소 입력
2. **네이버 서치어드바이저** (https://searchadvisor.naver.com) — 사이트 등록 → 인증키를 관리자 [검색 노출]에 붙여넣기 → 사이트맵 제출 (`/sitemap.xml`)
3. **구글 비즈니스 프로필** (https://business.google.com) — 업체 등록 → 서비스 지역 설정
4. **구글 서치콘솔** (https://search.google.com/search-console) — 속성 추가 → 인증키 붙여넣기 → 사이트맵 제출

## 8. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 로그인이 안 돼요 | 비밀번호를 8번 틀리면 10분간 잠깁니다. 잠시 뒤 다시 해 보세요. |
| "비밀번호가 설정되지 않았습니다" | 1번 [처음 설정]의 `ADMIN_PASSWORD` 를 넣어 주세요. |
| 저장했는데 다른 휴대폰에서 안 보여요 | 미리보기 모드(노란 안내)라면 Supabase 연결이 필요합니다. |
| 사진이 안 올라가요 | JPG·PNG·WEBP 만 됩니다. 아이폰 HEIC 사진은 [설정 > 카메라 > 포맷 > 높은 호환성]으로 찍어 주세요. |
| 글을 잘못 바꿨어요 | 칸 옆 [기본값] 또는 맨 위 [전체 기본값으로] |
