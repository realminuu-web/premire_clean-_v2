### 1. 전화번호 및 카카오톡 상담 링크 바꾸기
- **수정 위치**: `site.ts` 파일의 `contact:` 부분
```typescript
contact: {
  phone: '1800-0000',      // 👈 여기에 사장님 대표 전화번호를 적으세요 (화면 표시용)
  phoneTel: 'tel:1800-0000', // 👈 전화 걸기 링크 (앞에 tel: 을 꼭 유지해 주세요)
  operatingHours: '매일 08:00 ~ 21:00 (연중무휴)', // 👈 상담 시간
  kakaoChatUrl: 'https://open.kakao.com/o/사장님오픈카톡주소', // 👈 1:1 카카오톡 오픈채팅 주소
  instagramUrl: 'https://instagram.com/사장님계정', // 👈 인스타그램 주소
}
```

### 2. 사업자 정보 및 대표자명 바꾸기
- **수정 위치**: `site.ts` 파일의 `company:` 부분 (웹사이트 맨 밑 푸터에 표시됨)
```typescript
company: {
  corporateName: '(주)프리미어클린마스터', // 👈 상호명
  ceo: '김대표',                         // 👈 대표자 성함
  businessNumber: '123-85-67890',         // 👈 사업자등록번호
  telecomSalesNumber: '2026-서울강남-0123호', // 👈 통신판매업신고번호
  address: '서울특별시 강남구 테헤란로 152', // 👈 회사 주소
}
```

### 3. 인스타그램 사진 노출 개수 조절하기
- **수정 위치**: `site.ts` 파일의 `instagram:` 부분
```typescript
instagram: {
  // 💡 숫자만 1, 2, 3, 4, 6 중 원하는 숫자로 바꾸시면 화면에 바로 반영됩니다!
  // - 1: 대표 사진 1장만 화보처럼 크게 돋보입니다. (추천)
  // - 3: 가로 3열 격자로 정돈되어 나옵니다.
  // - 6: 6개 사진이 꽉 차게 나옵니다.
  instagramMaxPosts: 1, 
}
```

### 4. 구역별 정밀 청소 비포/애프터 사진 및 매뉴얼 바꾸기
- **수정 위치**: `site.ts` 파일의 `cleaningManualZones:` 부분
- 주방, 욕실, 창호, 수납장, 바닥 각각의 시공 전(`beforeImage`), 시공 후(`afterImage`) 사진 링크를 넣으시면 정밀 매뉴얼의 슬라이더 사진이 즉시 바뀝니다!
```typescript
{
  id: 'kitchen',
  zone: 'KITCHEN ZONE',
  title: '주방 딥클리닝 & 150℃ 고온 스팀',
  summary: '기름때와 탄화물을 완전 분해 세척하여 새 주방처럼 복원합니다.',
  beforeImage: '청소 전 사진 인터넷 주소(URL)', // 👈 시공 전 사진
  afterImage: '청소 후 사진 인터넷 주소(URL)',  // 👈 시공 후 사진
  disassemblyTargets: ['렌지후드 금속 필터망', '가스레인지 화구', '싱크대 하부 걸레받이'], // 👈 탈거 목록
}
```

### 5. 4대 고객 안심 보증 & 4대 장인 시공 원칙 문구 바꾸기
- **수정 위치**: `site.ts` 파일의 `trustBadges:` 및 `coreValues:` 부분
- **`trustBadges:` (고객 보호 4대 공식 보증 띠)**:
  - 'KB손해보험 5억', '100% 안심 후불제', '3일 무상 A/S', '추가금 0원' 등 법적·금전적 고객 보호 서약 문구를 수정할 수 있습니다.
- **`coreValues:` (4대 장인 시공 원칙)**:
  - '100% 한국인 직영 마스터팀', '독일 명품 장비 & 친환경 세제', '전 구역 100% 완전 분리 탈거', '1:1 실시간 현장 소통 & 동행 검수' 등 현장 청소 기술과 원칙을 원하는 문구로 자유롭게 수정하세요.

### 6. 자주 묻는 질문(FAQ) 내용 바꾸기
- **수정 위치**: `site.ts` 파일의 `faqList:` 부분
- `question`에는 질문을, `answer`에는 답변을 자유롭게 적으시면 아코디언 메뉴에 자동으로 예쁘게 들어갑니다.

### 7. 관리자 비밀번호 바꾸기
- **수정 위치**: `site.ts` 파일의 `integrations.adminPassword`
```typescript
integrations: {
  adminPassword: '0000', // 👈 기본값 '0000'을 원하는 비밀번호로 변경하세요!
}
```
- **관리자 모드 접속 방법**:
  - 모바일: 우측 상단 햄버거 메뉴를 누르고 맨 아래 `[🔒 관리자 모드]` 클릭
  - PC: 웹사이트 맨 밑 푸터(Footer) 최하단 저작권 옆의 작은 `[관리자]` 링크 클릭
  - 위에서 설정한 비밀번호를 입력하면 고객 후기 작성 창이 열립니다. (일반 고객에게는 절대 노출되지 않습니다)

### 8. 관리자 후기 등록 & 스마트폰 사진 자동 압축/리사이징
- **후기 등록 시 자동 메인 반영**:
  - 관리자 창에서 고객명, 아파트명/평수, 서비스 종류, 별점, 후기 내용을 적고 등록하면 **메인 화면에 즉시 1순위로 반영**됩니다.
  - 메인 화면에는 항상 **최신 10개의 명품 후기**가 슬라이드 형태로 회전하며 표시됩니다. (이전 후기들도 DB/저장소에 안전하게 보관됩니다)
- **스마트폰 대용량 사진 자동 압축/리사이징**:
  - 최신 스마트폰(아이폰/갤럭시)으로 촬영한 10MB~20MB 초고화질 사진도 걱정 없이 바로 첨부하세요!
  - 시스템 내장 **HTML5 Canvas 초경량 압축 엔진**이 가로세로 800px 이하, 용량 60~80KB로 즉시 다이어트시켜 저장합니다.
  - 이 덕분에 모바일 접속 고객도 데이터 낭비 없이 0.1초 만에 사진을 빠르게 볼 수 있습니다.

### 9. 인스타그램 링크 및 시공 화보 큐레이션
- **왜 공식 API 연동 대신 '직접 선별 등록' 방식인가요?**:
  - **오류율 0% 보장**: 인스타그램 공식 API는 60일마다 보안 토큰이 만료되어 주기적으로 사진이 엑박으로 깨지는 고질병이 있습니다.
  - **시공 품질 100% 엄선**: 공식 API는 직원이 올린 점심 밥상, 일상 스토리까지 홈페이지 메인에 다 떠버립니다. 직접 선별 등록 방식을 통해 가장 깨끗하고 멋진 **최고급 비포&애프터 시공 화보**만 고객에게 노출할 수 있습니다!
- **인스타그램 사진 & 링크 수정 방법**:
  - `site.ts` 파일의 `instagram.posts` 목록에서 이미지 링크(`image`)와 해당 인스타 게시물 주소(`postUrl`), 좋아요 수(`likes`), 댓글 수(`comments`)를 원하는 대로 수정하세요.
  - 고객이 홈페이지에서 인스타그램 사진을 누르면 **해당 인스타그램 게시물 원본 페이지로 1초 만에 바로 이동**합니다.
